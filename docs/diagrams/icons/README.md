# Icons

Only the icons the diagrams use are committed.

- `aws/`: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) (Service icons, 64 px, release 07312026), used under the AWS terms for architecture diagrams. AWS marks and logos remain AWS's.
- `fa/`: [Font Awesome Free](https://fontawesome.com/license/free) 7.3.1 (icons CC BY 4.0, license text in `fa/LICENSE.txt`).

Regenerate the diagrams with `uv run docs/diagrams/build.py`.
